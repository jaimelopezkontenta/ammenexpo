# General Sans

La tipografía de toda la interfaz. Es la sustituta libre de **Aeonik**, que es la del
montaje de diseño (`diseno/`) y es comercial.

- Origen: [Fontshare](https://www.fontshare.com/fonts/general-sans), de Indian Type Foundry.
- Licencia: **Fontshare Free License**, el fichero `FFL.txt` de al lado. Permite uso
  comercial, incrustar en apps y distribuir con el producto; no permite venderla suelta.
- Aquí van solo las cuatro pesas que usa la app —Regular, Medium, Semibold, Bold— en TTF.
  El paquete completo trae también itálicas, Light y Extralight, y una variable: si algún
  día hacen falta, se bajan del mismo sitio.

Las otras dos familias **no** viven aquí porque llegan como paquete npm:
`@expo-google-fonts/lora` para la lectura larga y `@expo-google-fonts/cormorant-garamond`
para lo editorial. Se cargan todas juntas en `app/_layout.tsx`.
